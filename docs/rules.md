# ひらがじゃん 裁定表

アプリが自動判定しない部分(あがりの成立・役の妥当性)を、遊ぶ前にみんなで確認しておくための表。
迷ったときはこのページを見ながら口頭で相談し、最後は宣言者(または場の合意)が「成立」「取り消し」を押す。

## 基本情報

| 項目 | きほんルール | じょうきゅうルール |
|---|---|---|
| 配布枚数 | 7枚 | 13枚 |
| あがり枚数 | 8枚 | 14枚 |
| 完成形 | 2文字 + 3文字 + 3文字 | 2+3+3+3+3、または 2文字×7組(七対子) |
| ポン | なし | あり(誰の捨て札からでも) |
| ロン | なし | あり(誰の捨て札からでも) |
| 山札切れ | 全員の捨て札をシャッフルして山札に戻す | 同左 |
| 手番 | 時計回り。ポンで手番が移る | 同左 |

カード内訳(全120枚、「を」「ん」以外の待ちカード「?」は不使用):

- 清音45種 × 2枚(あ〜わ、ん含む)= 90枚
- 濁音・半濁音25種 × 1枚(が〜ぽ)= 25枚
- 拗音・長音「っ・ゃ・ゅ・ょ・ー」× 1枚 = 5枚

## あがりの判定(手動)

1. あがったと思ったプレイヤーが「あがり!」ボタンを押す(枚数がぴったりのときだけ押せる)
2. 全員の画面に、そのプレイヤーの手札が**スペースの位置で言葉ごとに区切られて**大きく表示される
3. 声に出して読み上げ、実在する言葉になっているか全員で確認する
4. なっていれば宣言者が「成立!」、なっていなければ「取り消し」を押す
   - 取り消すと、ツモあがりは捨てるフェーズに戻る。ロンあがりは取ったカードを河に戻し、ポン・ロンの受付をやり直せる
5. 判定に迷う言葉(方言・固有名詞・略語など)は、遊ぶ前にクラス/グループでルールを決めておくと揉めない

**判定の目安(例)**

| ケース | 対応の例 |
|---|---|
| 辞書に載っている言葉かどうか怪しい | 事前に「辞書に載っている言葉のみ」「知っていればOK」など基準を決めておく |
| 固有名詞(地名・人名)を使いたい | 遊ぶ前に許可するか決めておく(初期設定は不可推奨) |
| 「ん」から始まる/1文字の組 | 2文字・3文字の組にする必要があるため、「ん」単独では組にならない |
| 促音・拗音・長音(っ・ゃ・ゅ・ょ・ー)の扱い | 単独の1文字として数える(「きゃく」= き+ゃ+く の3文字)。文字数のカウントに注意 |
| 七対子(じょうきゅうのみ) | 同じ文字のペア×7組。組ごとに違う文字である必要はルールとして定めていないので、事前に決めておく |

## ポンの手順(じょうきゅう)

1. 誰かが捨てたカードに対して、他のプレイヤーは「ポン」を押せる(自分の捨て札にはポンできない)
2. 自分の手札から、捨てられたカードと同じ文字の札を2枚選ぶ
3. 「ポンする」を押すと、捨て札+選んだ2枚が場に固定された組(meld)になり、以後は並べ替えられない
4. ポンしたプレイヤーがそのまま1枚捨てる。手番はポンした人の次のプレイヤーに移る
5. 受付時間(部屋設定で3〜8秒、または「次の人が引くまで」)を過ぎても、次の手番の人がまだ引いていなければポン・ロンは可能(早い者勝ち)

## ロンの手順(じょうきゅう)

1. 誰かが捨てたカードで自分の手札がちょうど14枚(七対子含む)になる場合、「ロン」を押せる
2. 手札に捨てられたカードが加わった状態で、宣言モーダルに言葉ごとの区切りが表示される
3. 成立すればそのプレイヤーの勝ち。取り消せば河にカードが戻り、ポン・ロンの受付が続く

## その他の裁定

- **同時にポン/ロンを宣言した場合**: アプリはどちらか片方の操作が先にサーバーへ届いた方を採用する(通信のトランザクションで解決)。ほぼ同時押しでは早く押した方が勝つとは限らない点に注意
- **手札の非公開設定**: 他人には枚数しか見えないが、データ自体はサーバー上に全員分置かれている(信頼ベースの実装)。カンニング防止を厳密にしたい大会などでは「公開」設定を推奨
- **接続が切れたプレイヤー**: 現状は自動退出・自動スキップの仕組みがない(README「今後決めること」参照)。抜けた人がいる場合はホストや周りの人が声をかけて進行する
